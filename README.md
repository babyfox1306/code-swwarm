# CODE SWARM

Programming game — viết Lua để điều khiển drone đào quặng và nạp về base.

**Engine:** LÖVE2D + Lua  
**Status:** V0.1 in development (see [Issue #1](https://github.com/babyfox1306/code-swwarm/issues/1))

## Chạy game

```bash
love .
```

(Yêu cầu [LÖVE 11.x](https://love2d.org/) trong PATH.)
